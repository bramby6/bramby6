### 💻 Architecture Showcase: Enterprise Modular Monolith

> *A custom-engineered, high-performance enterprise architecture designed from scratch to seamlessly bridge the gap between monolithic efficiency and microservices scalability.*

<details>
<summary><b>🔍 Click to expand custom architectural highlights</b></summary>

<br>

* **Modular Monolith & Custom Plugin Architecture (`.jar`):** Designed from the ground up, powered by a custom centralized security kernel (`helper.jar`) coupled with dynamically loaded, decoupled domain plugins (`auth.jar`, `sales.jar`, `inventory.jar`, etc.).
* **Flexible Deployment Topology:** Executes as a unified monolith for resource efficiency or scales out horizontally into standalone microservices on **MicroK8s** without breaking loose-coupling design principles.
* **Isolated Data Domains & OpenFeign:** Completely eliminates cross-module foreign key bottlenecks by enforcing dedicated databases per domain and utilizing **OpenFeign** for inter-module communication.
* **Hybrid Stateless Security:** Implements robust **JWT (supporting HMAC-SHA256 or asymmetric RSA Public/Private Key pairs)**, coupled with session-bound encrypted cookies and dynamic per-login salts to mitigate session hijacking and token replay attacks.
* **Performance Optimization:** Leverages **Hibernate Second-Level Cache (L2C) backed by Caffeine** to eliminate cross-module database query latency and boost throughput.
* **Lightweight SPA Frontend:** Delivers a responsive, low-overhead UI using **Vanilla JS & jQuery**, featuring dynamic menu rendering driven by granular permission matrices and encrypted `localStorage`.

</details>
